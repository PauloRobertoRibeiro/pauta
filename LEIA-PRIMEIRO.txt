PAUTA 0.2 — LEITURA MUSICAL E POLIRRITMOS

COMO ABRIR NO WINDOWS
1. Extraia o ZIP inteiro para uma pasta nova, por exemplo Pauta-Pronto.
2. Abra INICIAR-PAUTA.bat com dois cliques.
3. O navegador abre em http://localhost:4317.
4. Mantenha a janela preta aberta durante o estudo. Ctrl+C encerra o servidor.

A versão compilada já está incluída em out. Não precisa do Cursor, npm install
ou internet para estudar. Precisa do Node.js instalado no computador.
Se o iniciador disser que não encontra Node.js, instale a versão LTS de
https://nodejs.org e abra novamente INICIAR-PAUTA.bat.
Não abra out/index.html diretamente: use o iniciador.

Se uma versão antiga já estiver usando a porta 4317, encerre sua janela
antes de abrir esta versão. Preserve sua pasta antiga como cópia.
O iniciador roda apenas no próprio computador, sem abrir acesso pela rede.

COMO ESTUDAR
Notas: escolha o nível e responda pela tecla com a oitava correta.
As teclas aparecem em ordem de semitom. Role a faixa para ver outras oitavas.
Use Ouvir a nota quando precisar. Próxima nota libera após a resposta.
Ritmo: ouça, depois Começar a tocar. Espere a contagem e bata no início
DAS NOTAS (não nas pausas). Repete dois compassos; BPM em 6/8 é a semínima
pontuada. Um novo compasso ou troca de nível cancela a tentativa em andamento.
Polirritmos: escolha o ciclo. Ouvir toca as duas vozes por quatro ciclos;
no modo tocar a voz escolhida fica muda. Bata nela enquanto ouve a outra.
Use o botão grande, barra de espaço ou Enter com o botão focado.
Trilha: veja as metas, exporte e restaure seu progresso.

PROGRESSO
Fica no navegador e endereço usados. Use sempre http://localhost:4317
para não alternar entre origens. Exportar progresso gera um JSON.
Restaurar cópia substitui o progresso após confirmação.
Não há conta, nuvem nem sincronização automática entre dispositivos.
Limpar dados do navegador pode remover o progresso. Exporte regularmente.
O armazenamento bloqueado gera aviso; nessa situação exporte antes de fechar.

SONS E MEDIÇÃO
O som inicia por clique. Sons de notas são sintetizados, não gravações de piano.
A avaliação compara o início de cada toque com os ataques esperados; não mede
quanto tempo você segura a nota. Toques extras reduzem a pontuação.
Fones Bluetooth e o aparelho podem acrescentar atraso; prefira fones com fio.
Trocar de aba interrompe o exercício e não grava a tentativa incompleta.

PARA CONTINUAR DESENVOLVENDO
O código-fonte completo está incluído no mesmo pacote.
Node.js 22 LTS ou superior recomendado para desenvolvimento.
npm ci
npm run check     (testes musicais e validação dos dados)
npm run lint
npm run build     (atualiza a pasta out)
npm start         (abre o servidor local; visite localhost:4317)
npm run dev       (modo de desenvolvimento)

TESTES E LIMITES DA ENTREGA
Veja VERIFICACAO.txt. O aplicativo foi testado em Chromium no ambiente Linux.
O arquivo .bat é para Windows; sua execução no seu PC ainda precisa ser conferida.
A compilação e os arquivos de som/fontes são locais. Não há serviços pagos.
